# Dynamic Routing Protocols Implementation Using Cisco Packet Tracer

## Project Overview
Implemented and documented four dynamic routing protocols—RIP, OSPF, EIGRP, and BGP—using Cisco Packet Tracer.

The project demonstrates router configuration, routing protocol implementation, and network communication across a multi-router topology.

## Tools and Technologies
- Cisco Packet Tracer
- Cisco Routers
- RIP (Routing Information Protocol)
- OSPF (Open Shortest Path First)
- EIGRP (Enhanced Interior Gateway Routing Protocol)
- BGP (Border Gateway Protocol)

## Network Topology
The simulated network consists of:

- 3 Routers
- 3 Servers
- 6 PCs

The project documentation includes router configurations and routing protocol demonstrations.

## Routing Protocol Implementation

### 1. RIP — Routing Information Protocol
Configured RIP to demonstrate dynamic route exchange between routers.

### 2. OSPF — Open Shortest Path First
Implemented OSPF to demonstrate link-state routing within a simulated network.

### 3. EIGRP — Enhanced Interior Gateway Routing Protocol
Configured EIGRP to demonstrate dynamic route exchange using Cisco routing technology.

### 4. BGP — Border Gateway Protocol
Implemented BGP configuration to demonstrate routing between autonomous systems.
